 1. WHAT IS SEARCHLIGHT 98?
-----------------------------------------------------------------------------
Your Programs menu keeps growing. Searchlight 98 puts everything you have
installed on one panel, sorted into groups, with a search box that finds any
program or Control Panel setting as you type.

Press CTRL+SPACE anywhere in Windows, type a few letters and press ENTER.
Searchlight 98 runs in the system tray, next to the clock.

-----------------------------------------------------------------------------
 2. SYSTEM REQUIREMENTS
-----------------------------------------------------------------------------
 - Microsoft Windows 95, 98, 98 Second Edition or Millennium Edition
   (also runs on Windows NT 4.0 and 2000)
 - 640 x 480 display or better; 800 x 600 recommended
 - 1 MB of memory, 300 KB of free disk space

Searchlight 98 is a single small program. It needs nothing else installed.

 3. USING SEARCHLIGHT 98
-----------------------------------------------------------------------------
 Open Searchlight .......... CTRL+SPACE, from any program. Or double-click
                             the magnifier icon next to the clock.
 Search .................... Just type. Program names, parts of names and
                             initials all work: "mm" finds Midtown Madness,
                             "res" finds the Display settings.
 Pick a result ............. UP and DOWN arrow keys, or point with the mouse.
 Start it .................. ENTER, or click it.
 Pin to Favorites .......... Drag a program to the Favorites box and drop it
                             where you want it. Up to 5 favorites. Drag a
                             favorite sideways to change the order.
                             Pinned programs show a yellow star.
                             Keyboard: press F2 on a search result.
 Start a favorite .......... CTRL+ALT+1 to CTRL+ALT+5, from any program,
                             without opening Searchlight. The number is
                             shown on each favorite. This can be turned
                             off in Options. On keyboards where ALT GR and
                             a number type a character, that number is
                             left alone.
 Remove a favorite ......... Point at it and click the small X in its
                             corner. Searchlight asks before removing it.
 More about a program ...... Right-click it for a menu: Open, Open
                             Containing Folder, Properties, Pin, Hide, and
                             Uninstall if Windows knows how to remove it.
 Move to another group ..... Drag the program onto the other group.
 Your habits ............... Programs you start often move up in the
                             results. After a while "w" finds the one you
                             always mean.
 Recent .................... The last 5 programs you started from
                             Searchlight appear automatically. To take one
                             off, point at it and click the X in its corner.
 Close Searchlight ......... ESC, the X button, or click anywhere else.
 Rescan programs ........... F5, after you install something new.
                             Searchlight also rescans by itself.

 MORE THAN PROGRAMS
 Documents ................. Searching also finds what is in My Documents
                             and the documents you opened lately. Programs
                             are listed first. Documents can be pinned too.
 Sums ...................... Type a sum, such as 12*4+2, and the answer is
                             the first result. ENTER puts it on the
                             Clipboard. Use + - * / ^ ( ) and sqrt( ).
                             1.5 and 1,5 both mean one and a half.
 Run ....................... Type what you would type in Start, Run: the
                             name of a program (notepad, regedit), a folder
                             or file (C:\WINDOWS), or a web address
                             (www.example.com). A Run row appears in the
                             results. What follows a program's name is
                             given to it: notepad c:\autoexec.bat
 Screen .................... Type a screen size, such as 800x600, or a size
                             and the colors, such as 1024x768 16. ENTER
                             changes the screen. If you do not say within
                             15 seconds that you can read it, the old
                             screen comes back.
 Shut down later ........... Type "shutdown in 30" or "restart in 10". The
                             number is minutes. Windows warns you half a
                             minute before. To stop the countdown,
                             right-click the magnifier icon.
 Shut down now ............. Search for Shut Down, Restart Windows, Log Off,
                             Stand By or Restart in MS-DOS Mode. Each asks
                             before it does anything.

 RUNNING PROGRAMS
 See what is running ....... TAB, or click the Running button. Open windows
                             come first, then the programs that run in the
                             background. TAB goes on to Startup and then
                             back to the programs. SHIFT+TAB goes the
                             other way.
                             CTRL+SHIFT+SPACE opens it from any program.
                             Pressed again, it steps to the next program,
                             so it can be used in place of ALT+TAB.
 Gauges .................... Above the list: how busy the processor is, how
                             much memory is in use, and how much of the
                             system resources is left. They move once a
                             second. The disk cache is not counted as
                             memory in use, because Windows gives it back
                             when a program needs it.
                             F1, or a click on the gauges, shows the figures
                             behind them.
 Memory .................... Each row shows the memory of the program and
                             its own data. The Windows libraries a program
                             loads are left out: they are shared by all
                             programs and are in memory only once.
                             Windows 95 and 98 do not keep track of
                             processor time for each program, so there is
                             no such column.
 Find one .................. Just type part of its title or file name.
 Switch to a window ........ UP and DOWN, then ENTER. Or click it.
                             TAB and ENTER returns to the window you were
                             in before, the same as ALT+TAB.
 Close a window ............ DEL, or click the X at the end of its row.
                             If the program asks whether to save your work,
                             Searchlight steps aside and shows the question.
 End a program now ......... SHIFT+DEL. For programs that stopped responding
                             or have no window. Searchlight asks first:
                             work you did not save in that program is lost.
                             Parts of Windows itself cannot be ended.

 STARTUP PROGRAMS
 See what starts ........... TAB twice, or click the Startup button. The
                             list shows every program that starts together
                             with Windows, and where it starts from.
 Switch one off ............ SPACE or ENTER, or click its tick box. It stays
                             on the list, without the tick, and can be
                             switched back on the same way. The change
                             counts from the next time Windows starts.
 Find one .................. Just type part of its name or command.
 Good to know .............. Nothing is deleted. Searchlight moves entries
                             to the same places the System Configuration
                             Utility of Windows 98 uses, so either program
                             can switch them back on. Entries that start
                             from WIN.INI are shown but cannot be changed.

 Help ...................... F1 opens this file.
 Change the hotkeys ........ Right-click the magnifier icon next to the
                             clock and choose Change Hotkeys. The one for
                             the running programs can be set to (none).
 Options ................... Right-click the magnifier icon next to the
                             clock and choose Options.

 OPTIONS
 Icons ..................... Icons can be shown or left out in the program
                             lists, the running programs and the startup
                             programs, each on its own. Where they are left
                             out, a coloured square with the first letter
                             of the name stands in. This uses less memory
                             and fewer system resources.
 Load icons when shown ..... Ticked, an icon is loaded the first time its
                             program comes into view. Not ticked, all icons
                             are loaded in the background after start-up:
                             scrolling is smoother, more memory is used.
 Backdrop .................. While Searchlight is open, the rest of the
                             screen is blurred and darkened. Opacity sets
                             how dark: 0% leaves the screen as it is, 100%
                             makes it black. Blurring needs High Color
                             (16 bit) or better. A black backdrop does not.
 Stop Searchlight .......... Right-click the magnifier icon, choose Exit.

Searchlight also knows the Control Panel and system tools, and understands
what they are for. Try "uninstall", "resolution", "startup" or "shutdown".

-----------------------------------------------------------------------------
 4. CUSTOMIZING SEARCHLIGHT 98
-----------------------------------------------------------------------------
 CATEGORY.TXT   Move a program to a different group, or hide it.
                Searchlight writes this file for you when you drag a
                program to another group or choose Hide from its menu.
                To bring back a hidden program, or to make a new group,
                edit the file in Notepad.
 EXTRA folder   Put shortcuts here for programs that are not on your
                Start Menu.

Both are in the folder where Searchlight 98 is installed, normally
C:\Program Files\Searchlight 98. Press F5 in Searchlight after a change.

 5. TROUBLESHOOTING
-----------------------------------------------------------------------------
 Nothing happens when I press CTRL+SPACE.
     Look for the magnifier icon next to the clock. If it is missing,
     Searchlight 98 is not running: start it from the Start Menu. To start it
     with Windows, reinstall and tick "Start Searchlight 98 automatically".

 A message says the hotkey is used by Windows or another program.
     Right-click the magnifier icon, choose Change Hotkeys, and pick another
     combination.

 The processor gauge always shows 100%.
     Searchlight shows what Windows reports, the same figure as System
     Monitor. Programs that cool the processor, such as Rain, Waterfall,
     CpuIdle and AmnHLT, halt it whenever no program needs it. Windows
     counts that as work and reports 100% for as long as they run.

 The Resources gauge says "not available".
     Searchlight reads this figure through Resource Meter, which is an
     optional part of Windows. To add it, open Control Panel, Add/Remove
     Programs, Windows Setup, System Tools, and tick System Resource Meter.

 Another gauge says "not available".
     Windows NT and 2000 do not report those figures the way Windows 95 and
     98 do. On Windows 98, SLIGHT98.LOG says which gauges were found.

 A program is in the wrong group.
     Drag it onto the group it belongs in.

 There is no Uninstall in the menu of a program.
     Searchlight only offers it when it is sure which entry of Add/Remove
     Programs belongs to the program. Use Add/Remove Programs instead.

 "Restart in MS-DOS Mode" is not found.
     Windows makes the file it needs the first time you choose Restart in
     MS-DOS mode from the Shut Down box. Do that once.

 Something else is wrong.
     SLIGHT98.LOG in the Searchlight 98 folder lists what happened at
     start-up. It helps when reporting a problem.

-----------------------------------------------------------------------------
 6. UNINSTALLING
-----------------------------------------------------------------------------
Open Control Panel, Add/Remove Programs, choose Searchlight 98 and click
Add/Remove. Or use "Uninstall Searchlight 98" in the Start Menu.
