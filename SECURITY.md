# Security

## Supported versions

Fixes are made to the latest release.

## Reporting a vulnerability

Report security problems privately through GitHub: open the **Security** tab of this repository
and choose **Report a vulnerability**. Do not open a public issue.

Include the version of Searchlight 98, the version of Windows, and the steps needed to reproduce
the problem.

## Scope

Searchlight 98 runs on Windows 95 and Windows 98. These systems have no user permissions and no
separation between programs, and they no longer receive security updates. Searchlight cannot
provide protections that the operating system does not have.

Reports are useful where Searchlight itself makes a system less safe than it would otherwise be,
for example by running something the user did not choose, or by mishandling a file name, a
shortcut or a registry value.
